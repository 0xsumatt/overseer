How this works

Positions refresh about every 60 seconds and settled funding about every 5 minutes. Requests run one at a time, so long funding histories can take longer to catch up. Financial readings and read-only tokens stay only in page memory and are lost on refresh.

A Lighter single-account read-only token covers only its index; an all-accounts token covers discovered accounts. Without one, private funding may be incomplete. Never enter a signer or trading key.

Addresses and labels use only this tab’s sessionStorage, not a login or address database. They survive refresh; browser session restoration may retain them. Other fresh tabs are independent. Use Manage to clear this tab’s saved list.

Longs and shorts offset only within the same asset; different assets are never treated as a hedge. Token balances and collateral are separate from perpetual exposure. Native amounts keep their reported currency with no assumed stablecoin peg. USD estimates use current FX, not historical settlement FX. Unavailable amounts are not zero.
